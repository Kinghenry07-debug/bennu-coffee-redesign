# Bennu Coffee — Modern Responsive Web Redesign Concept

A modern, high-performance web redesign concept for **Bennu Coffee**, Austin’s iconic 24-hour neighborhood café. Built with a focus on dark-mode espresso aesthetics, clean component architecture, and seamless mobile responsiveness.

---

## ☕ Key Features

- **24/7 Café Vibe & Branding:** Custom dark-themed UI matching Bennu's signature warm espresso aesthetic.
- **Literary Gourmet Mochas Spotlight:** Interactive showcase of Bennu's world-famous signature mochas (*The Raven*, *Moby Dick*, *Pride & Prejudice*).
- **Responsive Layout:** Optimized for all screen sizes (mobile, tablet, desktop) using modern CSS principles.
- **Performance Optimized:** Clean single-file layout with instant loading times and zero bloat.
- **Austin Location Guide:** Direct access to East MLK & Central Congress shop details and 24-hour operational hours.

---

## 🛠️ Tech Stack

- **HTML5 & Modern JS**
- **Tailwind CSS** (via CDN integration)
- **Hosted on:** Vercel
